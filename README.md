# B 站学习净化器 · Bili Study Filter

> 把 B 站推荐流调成适合自习的样子：屏蔽 AI 流水线、游戏短视频和同质化科普，顺着你的关注/收藏做一张兴趣地图，一边深耕，一边拓界，顺手考古短视频时代之前的硬核长视频。

![效果预览](docs/demo-preview.png)

这是一个 **Chrome / Edge 浏览器扩展**（Manifest V3），只作用于 `bilibili.com`。它不举报、不修改 B 站数据，只改变你本地的显示方式：默认把干扰项模糊，点一下就能展开；所有判断和缓存都在本机完成。

## 它解决什么问题

| 你的感受 | 插件对应做法 |
| --- | --- |
| 同一个科普选题，几十个人一起发，内容相似、质量参差 | **同题聚类**：识别同一推荐流里的同题视频，按学习价值保留最佳版本，其余淡化并标注 |
| 竖屏区、游戏区全是 1–2 分钟的低质短视频 | **游戏 / 竖屏短视频规则**：命中游戏词或竖屏封面且时长过短时，模糊或隐藏 |
| AI 营销号批量生产“认知觉醒”“底层逻辑”“盘点 AI 神器” | **AI / 营销号雷达**：AI 生成声明、营销话术组合、流水线标题模板，分级处理 |
| 想看更长的、有深度的内容，但推荐流只给短的 | **专注模式**：折叠所有非知识向短视频，只留下长内容和知识向内容 |
| 想找短视频时代之前的好科普 | **考古模式**：按当前选题检索 2021 年前的长视频，按收藏率、时长、年代、知识密度排序 |
| 推荐流总是同一类内容，越刷越窄 | **信息茧房提示 + 兴趣探索**：统计本页领域分布，单一领域过重时提示“换换脑子”，用画像生成深耕/拓界/经典三条路线 |
| 首页有推广直播、广告和空位，想看点科技/计算机/电子信息的科普 | **首页清理 + 学习布局**：默认清理推广直播/`floor-single-card`/广告/大 banner/轮播，剩余卡片紧凑回流，顶部科技专区补位 |
| 想按自己的喜好换背景 | **页面背景**：渐变、纯色或图片 URL，可调透明度/模糊/暗化 |
| 不想被“一刀切”，也不想再也看不到某个 UP | **可解释 + 可恢复**：每条标记都有原因，可单条展开、放行 UP、加白名单、调阈值 |

插件不会假装自己是内容审核。它是一个**本地的注意力过滤器**：把选择权从推荐算法手里拿回来一点。

## 功能一览

### 1. 游戏短视频 / 竖屏短视频

- 命中“王者荣耀 / 原神 / 五杀 / 上分 / 开黑 / 抽卡 / 吃鸡……”等游戏特征，且时长 ≤ 5 分钟 → 高优先级，默认模糊。
- 竖屏封面（`9:16`）+ 时长 ≤ 3 分钟 → 高优先级。
- 长游戏纪录片（比如 1 小时的游戏史）不会被模糊，只会得到一条低优先级标注。
- 时长阈值可在设置里改。

### 2. 疑似 AI 营销号 / 营销号话术

- “AI 生成 / AI 配音 / 数字人 / 一键生成 / Sora”等 AI 声明。
- “AI + 颠覆 / 暴富 / 搞钱 / 神器 / 变现 / 风口”等营销组合。
- “认知觉醒 / 底层逻辑 / 普通人翻身 / 强者思维 / 每天一句”等鸡汤流水线。
- “注意看，这个男人叫小帅 / 一口气看完 / 已完结”等影视解说模板。
- **正规 AI 课程会被放行**：标题含“公开课 / 课程 / 原理 / 论文 / 系统学习”等知识标记，且时长足够的长视频，不会被当成 AI 营销号。

### 3. 同质化选题聚合

只在**首页推荐、视频页相关推荐、UP 空间**生效；搜索结果不做折叠，避免把你想看的都藏起来。

- 用中文 n-gram + 文档频率找出同一页里反复出现的“主题词”（比如“信息论”“量子”“线性代数”）。
- 同一主题 ≥ 3 条时成组；按学习价值保留一条“同题最佳”，其余淡化并标注 `同题 ×N`。
- 学习价值综合：时长、播放/收藏/点赞互动率、知识标记、UP 质量加权，减去标题党 / AI / 游戏短视频扣分。
- 点击 `同题 ×N` 角标可看到“最佳版本”并一键打开，也可以直接考古同题。

### 4. 考古模式

- 在面板或弹窗点“考古”，输入/确认选题，检索 **2021-12-31 之前**发布的视频。
- 默认只看 ≥ 10 分钟的长视频，可选 ≥ 5 / 30 / 60 分钟。
- 按收藏率、点赞率、播放量、时长、年代、知识标记综合排序。
- 结果缓存 24 小时；遇到 B 站风控（-412）会自动退避一次，并给出手动搜索入口。
- 详见 [考古模式](#考古模式)。

### 5. 专注学习

- 一键切换：非知识向短视频直接折叠，游戏 / AI / 营销号高优先级项隐藏。
- 底部会出现“已隐藏 N 个 · 显示”，点一下恢复本页全部内容。
- 适合考试周；不想用时切回“平衡”。

### 6. 可解释、可恢复

- 每个角标点开都有“为什么”：命中哪些词、时长多少、标题党几分、同题几条、最佳版本是谁。
- 可以：展开单条、收起、放行此 UP、考古同题、隐藏。
- 设置页有**规则测试器**：输入标题/时长/UP，实时看判定结果，调阈值不用猜。

### 7. 账号画像与兴趣探索

- 在面板点 **同步账号画像**：通过你当前登录的 B 站页面读取关注、收藏夹（最近观看默认关闭），在本机聚合成领域占比。
- **深耕领域**：你原本投入最多的方向，探索时优先给更长、更系统的内容。
- **拓界领域**：和你的主兴趣相邻、但没怎么接触的领域；用“通识/讲座/公开课”入口，不用标题党或对立情绪。
- **茧房提示**：统计当前页面的领域分布；单一领域占比超过阈值（默认 65%）时，右下角出现“本页 72% 游戏 · 换换脑子”。
- **三条探索路线**：
  - 深耕：延长已有兴趣，优先长内容与系统课程；
  - 拓界：补相邻领域，过滤 K12/儿童向/升学规划等低匹配内容；
  - 经典：只找 2021 年前的长视频。
- 所有画像只在本机保存，原始关注/收藏/历史列表不落盘，可一键清除。

> 这一块不是“用算法喂更多同类内容”，而是反过来：用画像找你的盲区。详见 [账号画像与信息茧房](#账号画像与信息茧房)。

### 8. 正则规则、画像校准与本页反馈

- **自定义屏蔽/放行支持正则**：每行一个普通词，或 `/^原神|^崩坏/i` 这样的正则；匹配标题、UP 名和标签。正则写错不会让插件崩溃，会忽略这一条。
- **画像校准**：把账号画像的领域占比和当前页面分布对齐，显示「游戏 +33% / 数学 -34%」和「画像盲区：生物、艺术」。
- **本页“少看同类”**：角标详情里可以按领域/同题少看同类内容，只影响当前页面会话；点“显示隐藏”恢复。不会调用 B 站“不感兴趣”接口，也不会改你的账号历史。
- **关注分组与收藏夹明细**：设置页可以展开查看每个关注分组、收藏夹的数量和领域标签，方便判断画像由什么构成。

### 9. 首页清理与科技学习布局

- **默认清理推广直播和广告**：`floor-single-card` 单卡（直播/电视剧/社情位）、`live.bilibili.com` 链接卡、`bili-video-card__info--ad`、`info--creative-ad`、推广小火箭图标、统计栏“广告/推广”角标、外部广告链接，以及 **顶部大 banner / 推荐轮播**，直接收起对应卡片或楼层，不留空位。
- **紧凑回流**：清理后给首页网格加 `grid-auto-flow: dense`，剩余卡片自动补位；被隐藏的 `.feed-card` 直接 `display:none`，不再保留占位。
- **顶部科技专区**：首页推荐流上方新增「今天看点硬核的」，默认放 4 条计算机 / 电子信息 / 科技 / AI 长视频，可“换一批”。
- **被屏蔽位置补位**：隐藏一个视频后，不再留下空格；原位置换成一条科技学习视频，可“换一个”。如果不想补位，空位会直接收起，信息流自动补上。
- **空楼层收起**：整个竖屏/低质楼层都被过滤时，连标题一起收起，不留下“竖屏·小视频”空壳。
- **模糊遮罩**：模糊卡片底部增加“学习净化 / 点击展开”的柔化遮罩，不再是一团糊图。
- **科技池**：按计算机、电子信息、科技、AI、数学、物理检索，过滤 K12、升学规划、影视解说、游戏和高风险 AI slop，优先 10 分钟以上、收藏率高的内容；缓存 12 小时。
- **可关**：设置页可以只保留顶部专区、只补位、隐藏顶部轮播、收起首页大 banner，或整个关掉。

### 10. 页面背景

- 设置页可选 **默认 / 雾蓝 / 暖白 / 深空 / 图片 URL**。
- 支持透明度、模糊、暗化遮罩；背景固定在最底层，不挡点击。
- 图片只接受 `http(s)` 或 `data:image`；不会上传到任何服务器，也不会改变 B 站内容。
- 提供实时预览，调完保存即可回 B 站看效果。

## 安装（3 分钟）

### 准备

- Chrome 111+ 或 Edge 111+（macOS / Windows / Linux 均可）。
- 本项目文件夹：`bili-study-filter`（或解压后的同名文件夹）。
- 如果你拿到的是发布包 `bili-study-filter-v1.5.1.zip`，解压后选择里面的 `bili-study-filter` 文件夹。
- **不要**直接选 ZIP 文件，Chrome 需要“解压后的文件夹”。

### 步骤

1. 打开 Chrome，地址栏输入 `chrome://extensions/`（Edge 为 `edge://extensions/`）。
2. 右上角打开 **开发者模式**。
3. 点 **加载已解压的扩展程序**。
4. 选择 `bili-study-filter` 文件夹（里面能看到 `manifest.json` 的那一层）。
5. 安装成功后会自动打开设置页；也可以点扩展图标 → “设置与白名单”。
6. 打开/刷新 `https://www.bilibili.com/`。右下角出现蓝色“学习净化”按钮即成功。
7. 建议把扩展固定到工具栏（拼图图标 → 图钉），方便看今日统计。

> 更新代码后：在 `chrome://extensions/` 点扩展卡片上的刷新按钮，再刷新 B 站页面。

### 卸载/重置

- 在扩展管理页移除即可。卸载会清除本地设置和缓存。
- 设置页 → 数据与备份 → **导出配置**，可备份白名单和阈值。

## 日常使用

### 角标含义

| 角标 | 含义 | 默认视觉 |
| --- | --- | --- |
| `游戏短视频` | 游戏特征 + 时长过短 | 模糊 |
| `竖屏短视频` | 竖屏封面 + 时长过短 | 模糊 |
| `疑似 AI 营销` | AI 生成声明 / AI 营销话术 | 模糊 |
| `营销号话术` | 鸡汤 / 成功学 / 流水线模板 | 模糊 |
| `影视解说流水线` | “注意看 / 小帅 / 一口气看完”模板 | 模糊 |
| `同题 ×N` | 同页有 N 条同题，这条不是最佳 | 淡化 + 虚线框 |
| `同题最佳 ×N` | 同题组里学习价值最高 | 绿色角标 + 绿框 |
| `标题党` | 标题党特征较强 | 淡化 |
| `专注模式` | 专注模式下被折叠的短视频 | 隐藏 |

- **点卡片**：第一次点击是“展开”，第二次才进入视频。
- **点角标**：打开详情，看原因、最佳版本、放行 UP、考古同题、**少看同类**。
- **点“展开/收起”**：单条控制。
- **首页顶部“今天看点硬核的”**：这是科技学习专区；右上角「换一批」换一组，「设置」调整领域和布局。

### 面板与快捷键

- 右下角 **学习净化** 按钮：打开悬浮面板。
- `Alt + B`：打开/收起面板。
- `Alt + A`：对当前页面选题打开考古。
- 面板里可以：切策略、切显示方式、开关规则、调短视频阈值、调同题最少条数、**同步账号画像**、打开**兴趣探索**、暂停本页、打开设置。
- 浏览器工具栏弹窗：看今日统计、快速开关、打开面板、考古当前选题。

### 三种策略

| 策略 | 适合 | 行为 |
| --- | --- | --- |
| **平衡** | 日常 | 默认阈值；高优先级模糊，同题保留最佳 |
| **专注学习** | 考试周 / 写作业 | 折叠非知识短视频；游戏 / AI / 营销号高优先级隐藏；同题最少 2 条就聚合 |
| **轻度** | 不想太激进 | 只处理很短的（2 分钟内）游戏/竖屏；标题党、娱乐规则关闭；同题 4 条起 |

### 显示方式

- **模糊**（推荐）：内容还在，但看不清；点击展开。
- **淡化**：降低透明度和饱和度，适合“我还想扫一眼标题”。
- **隐藏**：高优先级项直接不显示；底部出现“已隐藏 N 个 · 显示”恢复条。

> 中优先级项始终是“淡化”，低优先级项只记录、不打扰。这样不会把整个首页糊掉。

### 放行一个 UP

角标详情 → **放行此 UP**。会同时加入名称和 mid 白名单，之后这个 UP 的内容不再处理。也可以在设置页手动维护。

## 判定逻辑（它怎么判断）

插件没有调用大模型，也不会上传标题。判定完全在本地，由可解释的启发式规则完成：

1. **文本特征**
   - 游戏实体 + 游戏行为词
   - 娱乐 / 短剧 / 鸡汤 / 成功学词
   - 知识学科词 + 知识形式标记（公开课、课程、原理、推导、论文、第 X 讲）
   - AI 生成声明、AI 营销组合、数字人
   - 标题党模式：震惊、必看、99%、夸张标点、emoji 密度、模糊指代
2. **时长与封面**
   - 短视频 / 游戏短视频 / 竖屏短视频 / 娱乐短视频四组阈值
   - 竖屏通过 `--cover-radio` CSS 变量、类名、封面长宽比综合判断
3. **账号与白名单**
   - 白名单 mid / 名称 / 自定义放行词
   - 优质 UP 加权名单（只影响“同题最佳”排序，不会直接放行）
4. **同题聚类**
   - 中文 2–4 字 n-gram，过滤通用词和标题党词
   - 计算同一页面的文档频率，取 3 条以上共同主题词
   - 近似重复标题（Jaccard / 包含度）合并
   - 过大组按最强主题词拆分，避免“物理”这种上位词吞掉整页
5. **学习价值分**
   - 时长（对数）、播放、点赞率、收藏率、弹幕率
   - 知识核心词 / 标记、优质 UP、长视频加分
   - 标题党、AI、游戏短视频、营销话术扣分
   - 0–100 分，用于同题组内选“最佳版本”

**为什么 AI 课程不会被误伤？**
“ChatGPT 从入门到精通：提示词工程完整课程”虽然命中 AI 词，但同时有“课程 / 入门 / 完整课程”知识标记且时长 55 分钟，规则会把它归为知识向长视频；而“AI 生成！盘点最离谱的 AI 工具”只有 1 分钟、带 AI 生成声明，会直接高优先级。

**为什么长游戏视频只标注不模糊？**
你明确说过不想看 1–2 分钟的游戏短视频，而不是所有游戏内容。规则把“游戏 + 短”作为高优先级，“长游戏内容”只做低优先级标注。

## 考古模式

### 怎么用

1. 在 B 站搜索页/视频页，点右下角面板 → “考古”，或按 `Alt + A`。
2. 面板会自动填入当前页面的选题（搜索词，或从视频标题提取的关键词）。
3. 选年代上限、最短时长，点“开始考古”。
4. 结果按综合分排序；点封面/标题打开视频，点“在 B 站搜索页打开”看原始结果。

### 检索参数

- 接口：B 站公开搜索接口 `api.bilibili.com/x/web-interface/search/type`。
- 发布时间上限默认 `2021-12-31`（短视频大规模爆发前）。
- 开始时间 `2009-01-01`。
- 默认抓 2 页 × 20 条，客户端过滤掉“太新”和“太短”的。
- 排序：收藏率、点赞率、播放量、时长、年代、知识密度综合；标题党扣分。
- 缓存：24 小时；最多 40 个查询；设置页可清除。

### 风控说明

B 站搜索接口有频率限制。插件已经做了：

- 页与页之间 480ms 间隔；
- 遇到 `-412` 退避 1.4 秒重试一次；
- 结果缓存，重复查同一个选题不再请求；
- 失败后给出手动搜索链接（带 `pubtime_end_s` 参数）。

如果仍然被拦截，等 1 分钟再试，或直接在 B 站搜索页按“发布时间”排序。

### 选题提取

从标题里去掉“注意看 / 小帅 / 硬核科普 / 一个视频 / 完整课程”等噪声，保留“信息论 / 熵增定律 / ChatGPT / 提示词工程”这类主题词。提取结果会显示在输入框里，可以手动改。

## 账号画像与信息茧房

### 它读取什么

| 数据 | 是否默认读取 | 用途 |
| --- | --- | --- |
| 账号登录态 / mid / 昵称 | 是（点同步时） | 确认账号、标记画像归属 |
| 关注列表（默认前 3 页） | 是 | 从 UP 名、签名、关注分组推断领域 |
| 收藏夹列表 + 每个收藏夹前 20 条 | 是（默认最多 8 个收藏夹） | 领域占比、主题词；文件夹名权重更高 |
| 最近观看 30 条 | **否，需在设置里开启** | 补全画像 |
| 原始标题/关注名单/历史列表 | 不保存 | 只在同步过程中于内存聚合 |
| 聚合成领域占比、主题词、收藏夹摘要 | 保存到 `chrome.storage.local` | 生成探索推荐；可一键清除 |

- 需要你在当前浏览器登录 B 站，并至少打开一个 B 站标签页。
- 同步是**手动触发**的，不会在后台偷偷读取。
- 所有请求都从 B 站页面以你的登录态发起，和你在搜索框搜东西是同一类请求；没有插件服务器。
- 遇到 B 站风控（-412）时同步会失败并提示，稍后再试即可。

### 兴趣地图怎么用

1. 在 B 站右下角面板点 **同步账号画像**（或在设置页同步）。
2. 同步完成后，面板会显示你的领域占比，例如「数学 34% · 计算机 26% · 游戏 17%」。
3. 点 **探索** 打开兴趣探索弹窗：
   - **深耕**：从你的主要领域和主题词出发，优先更长、更系统的内容；
   - **拓界**：从相邻领域出发，优先通识/讲座/公开课，过滤儿童向、K12、升学规划等内容；
   - **经典**：只看 2021 年前的同类长视频。
4. 每条结果都标注“为什么”：深耕/拓界、领域、时长、收藏率。点“换一批”会换关键词重新检索（有 12 小时缓存）。
5. 设置页可以手动指定 **深耕领域** 和 **拓界领域**，覆盖画像自动推荐；点“按画像推荐兴趣”可以恢复自动建议。

### 茧房指标

- 把当前页面的视频标题映射到 15 个领域（数学、物理、计算机、生物/医学、化学/材料、工程、宇宙/地球、人文/历史、社科/经济、心理/认知、设计/艺术、语言/学习、游戏、娱乐、生活/健康）。
- 统计单一领域占比和归一化熵；当可分类内容 ≥ 6 条且最高领域占比 ≥ 65% 时，判定为“偏单一”。
- 面板显示「本页 物理 25% · 多样性 0.93」；达到阈值时右下角出现“本页 72% 游戏 · 换换脑子”的 chip，点击直接打开探索。
- **画像校准**会进一步指出「本页比你的画像多看了什么、少看了什么」，例如「游戏 +33% / 数学 -34%」，并给出「画像盲区：生物、艺术」。这比单看一个占比更能解释“我为什么觉得越刷越窄”。
- 这个指标只提示，不自动隐藏你的内容；是否换口味由你决定。

### 为什么用“相邻领域”而不是“对立内容”

“拓界”选的是和主兴趣相邻、可迁移的领域（例如数学 → 物理/计算机/哲学，游戏 → 设计/心理学/计算机），而不是故意推愤怒、对立或标题党内容。目标是把认知边界往外推一格，不是制造新的信息茧房。

### 控制与隐私

- 设置页 → 兴趣画像与信息茧房：开关“参考最近观看”“页面茧房提示”，调阈值和每路结果数，手动选领域，清除画像。
- 清除画像会同时清掉探索缓存；不影响 B 站账号本身。
- 画像里保存的是领域统计、主题词、收藏夹标题/关注分组摘要；不保存具体视频标题、关注名单、历史记录列表。
- 换电脑时可以通过“导出配置”带走设置，但账号画像不会导出；在新电脑重新同步即可。

## 首页学习布局

### 它长什么样

- **先清理**：推广直播、`floor-single-card`、广告卡、广告楼层直接 `display:none`；如果整个楼层都被清理，标题一起收起。
- **顶部专区**：插入在首页推荐流最上方，4 列卡片，标题、UP、时长、播放量；「换一批」只在本地池里轮换，不重复请求。
- **补位卡**：被隐藏的视频格会换成一条科技视频，带「学习补位 · 计算机」标签和「换一个」；它不是广告，也不占额外位置。
- **空位收起**：如果关闭补位、或某个楼层全被过滤，原网格项会 `display:none`，B 站网格自己回流，不会再留空白。
- **模糊遮罩**：模糊卡片保留一点上下文，但底部有清晰的操作提示，避免“糊成一片”。

### 科技池怎么来

- 默认从 B 站公开搜索接口检索 4 个方向：计算机、电子信息、科技、AI；可在设置页加数学/物理。
- 每个方向取一页结果，按以下规则排序：
  - 时长 ≥ 10 分钟，收藏率、点赞率、播放量；
  - 标题/标签/分区必须命中对应科技领域；
  - 过滤 K12、儿童向、升学/就业规划、影视解说、游戏、高风险 AI 营销；
  - 超长合集（> 6 小时）和低播放长合集降权，避免推荐 20 小时“全集”。
- 缓存 12 小时；设置页可「刷新科技池」或「清除科技缓存」。
- 不需要登录；不读取账号；请求从当前 B 站页面发出，和你在搜索框搜索等价。

### 设置

设置页 → **首页学习布局**：

- 清理直播推广 / 清理首页广告（含大 banner）/ 紧凑重排（默认开）；
- 顶部科技专区 / 被屏蔽位置补位 / 隐藏顶部轮播 / 收起首页大 banner；
- 选择科技领域；
- 学习池最短时长、数量；
- 刷新科技池 / 清除缓存。

> 这是非破坏式布局：只在 B 站原生网格里插入一个 section 和若干补位卡，不接管首页推荐 API。B 站改版时最坏情况是专区不出现，不影响原有过滤。

## 页面背景

设置页 → **页面背景**：

### 预设

- **默认**：不修改 B 站背景。
- **雾蓝 / 暖白 / 深空**：三套低对比渐变，适合长时间看。
- **图片**：填自己的图片 URL，固定铺满、居中裁切。

### 可调项

- **模式**：默认 / 渐变 / 纯色 / 图片。
- **纯色**：颜色选择器。
- **图片 URL**：`https://...` 或 `data:image/...`；只作为 CSS 背景加载，不上传。
- **渐变 CSS**：`linear-gradient(...)` / `radial-gradient(...)`。
- **不透明度**：0–100%。
- **模糊**：0–20px；大图建议 2–6px。
- **暗化遮罩**：0–60%，深色图建议 20–35%，避免文字看不清。

> 背景层是 `position:fixed; z-index:-1` 的独立图层，B 站主体容器会变透明以露出它；卡片和播放器仍保持原样。B 站要是改版把容器背景写死，最坏情况是背景只在边缘可见，不影响功能。

## 调参建议

- **只想屏蔽游戏短视频**：设置 → 识别规则，关掉除“游戏短视频”外的规则；显示方式选“模糊”。
- **考试周**：面板 → 专注学习；同题最少条数调到 2；短视频上限 5 分钟。
- **不想看任何 10 分钟以下**：短视频上限调到 10:00，开启专注学习；知识向内容仍会保留。
- **误伤某个 UP**：角标 → 放行此 UP；或在白名单里加名称/mid。
- **某类词老是被误判**：设置 → 自定义词 → 强制放行词，填标题里会出现的词。
- **同题聚合太激进**：同题最少条数调到 4–6，或关掉“同质选题聚合”。

## 隐私与安全

- **没有服务器。** 没有账号系统，没有埋点，没有远程配置。
- 所有设置、统计、考古缓存都在 `chrome.storage.local`。
- 唯一的外部请求是：你主动点“考古/探索/同步画像”，或首页科技专区需要加载时，向 `api.bilibili.com` 发起 B 站接口请求（带当前页面 Cookie，与你在 B 站里搜索/查看自己的关注收藏等价）。
- 首页科技池只按公开关键词搜索，不读取账号；缓存 12 小时。
- 自定义背景图片由浏览器按你填的 URL 直接加载，插件不上传、不代理。
- 账号画像相关数据只保存在本机；最近观看默认不读取；只读取你自己的账号，不支持输入他人 mid 抓取；可一键清除。
- 内容脚本只在 `bilibili.com` 下运行；不会读取其他网站。
- 不修改页面里的视频数据，不自动点赞/投币/举报，不发送任何内容。

## 已知限制

- **启发式会误判。** 词库和阈值不可能覆盖所有内容；请用“放行 UP / 白名单 / 自定义词 / 阈值”修正。默认是模糊而不是隐藏，误伤成本较低。
- **B 站 DOM 会变。** 插件用通用锚点 + 类名 + 时长文本识别卡片；如果 B 站大改版导致识别不到，需要更新选择器。当前版本已用真实首页/搜索页 SSR 快照验证。
- **同题聚合只在推荐场景生效。** 搜索结果不聚合，因为搜索本身就是同题。
- **考古依赖 B 站接口。** 接口风控/改版时可能失败；有缓存和手动搜索兜底。
- **不支持手机 App / 手机网页。** 只做桌面网页版。
- **不处理直播、番剧、课程付费页。** 只处理普通视频卡片。
- **“AI”不是万能标签。** 很多营销号不用 AI，很多 AI 内容也很有价值；插件看的是可观察的话术和形式，不是给账号贴永久标签。
- **账号画像依赖 B 站接口。** 需要登录 + 手动同步；接口改版、风控或未登录时会失败；原始数据不缓存，失败后重试即可。
- **领域分类是启发式的。** 一个标题可能同时属于多个领域；画像和茧房提示用于探索，不是给你下定义。
- **首页布局依赖 B 站 DOM。** B 站改版后专区可能不出现或样式失效；补位卡是原生网格里的附加节点，不会接管推荐 API。清除直播/广告依赖 `floor-single-card`、`info--ad` 等类名，B 站改版后可能漏掉；遇到问题可在设置页关掉对应开关。
- **页面背景只负责“露出背景”。** 如果 B 站某个容器把背景写死，可能只在边缘/间隙可见；可以提供截图，我补对应容器选择器。

## 设计借鉴（调研过的项目）

做这一版之前，专门去看了几个方向的现有项目。不是照搬，而是各取一个点：

### B 站 / 浏览器扩展

- [Turing222/bilibili_blocked](https://github.com/Turing222/bilibili_blocked)：按标题、UP、标签、分区、统计量屏蔽，支持正则和白名单，规则透明可导入导出。我们借鉴了 **正则自定义规则** 和“每条标记可解释”的思路，但没有做按评论/粉丝数这类需要额外接口的匹配，避免请求过重。
- [magicdawn/bilibili-app-recommend](https://github.com/magicdawn/bilibili-app-recommend)：把 App 推荐搬到桌面，并用 B 站“我不想看”做反馈。我们借鉴了 **“少看同类”** 这种即时反馈，但只做成本页会话级的本地隐藏，不调用 B 站的反馈接口，也不替用户改推荐历史。
- [fept-2024/Bilibili-Preference-Plugin](https://github.com/fept-2024/Bilibili-Preference-Plugin)：通过清除历史、模拟行为来直接改变 B 站推荐算法，提供历史画像/预设/随机化。这个思路很直接，但我们**没有采用**：修改账号历史不可逆、接口不稳定，也容易违反平台规则。我们改成“不碰账号，只在本机做画像 + 探索”。
- [NikoboiNFTB/DeSlop](https://github.com/NikoboiNFTB/DeSlop)：靠 GitHub 上维护的频道 blocklist 过滤 YouTube AI slop。我们借鉴了 **规则清单化、可审计**，但没有默认引入远程黑名单（供应链、误伤、隐私都不可控）；当前用本地启发式 + 可选手写正则。
- [qiye45/BlocksShortVideos](https://github.com/qiye45/BlocksShortVideos)：专门屏蔽 B 站短视频，轻量直接。我们的竖屏/短视频折叠和它有重叠，但额外做了时长、领域、同题和可恢复处理。
- [Bilibili Evolved](https://github.com/the1812/Bilibili-Evolved) / [BewlyBewly](https://github.com/hakadao/BewlyBewly)：成熟的 B 站增强项目，模块化和 UI 很值得学。我们坚持 **非破坏式 DOM 叠加**，不接管首页信息流。B 站 2026 年首页推荐 API 有调整，直接替换 feed 的项目维护成本很高，这也是我们保留原生页面的原因之一。

### 信息茧房 / 推荐多样性

- [Ground News 的 Blindspot](https://help.ground.news/en/articles/485057)：展示“某一侧没覆盖的故事”。我们把它转成 **领域盲区**：画像里没有、本页也没有的相邻领域。
- [Calibrated Recommendations (Steck, 2018)](https://dl.acm.org/doi/10.1145/3240323.3240372)：推荐分布应该和用户历史兴趣分布“校准”，而不是只追求点击。我们据此做了 **画像 vs 本页的偏差**，并把“深耕/拓界”作为显式控制，而不是让算法猜。
- [From Walls to Windows: Creating Transparency to Understand Filter Bubbles](https://ceur-ws.org/Vol-3898/paper2.pdf)：用透明化帮助用户理解茧房。我们的角标“为什么”、领域占比、画像偏差和盲区，都是这条思路的落地。

### 一句话总结取舍

**不做“替你改 B 站算法”这种事，也不默认拉远程黑名单。** 插件只在你本地做三件事：解释、标注、给你另一条可选的探索路径。这样风险最低，也最容易被你自己审计。

## 常见问题

**Q：为什么有些短视频没有被标记？**
A：可能时长识别不到（B 站改版）、没有命中游戏/竖屏/娱乐特征，或它被识别为知识向内容。可以在设置页用规则测试器试；也可以调高“短视频上限”并开专注模式。

**Q：为什么同题没有聚合？**
A：只对首页推荐、相关推荐、UP 空间生效；至少 3 条同题；标题差异太大时可能识别不到。可以调低“同题最少条数”。

**Q：同步账号画像失败？**
A：确认当前浏览器已登录 B 站，并至少打开一个 B 站标签页；从右下角面板同步最稳。若提示 -412，等 1 分钟再试；若提示未登录，先在 B 站登录。实在不行可以在设置里手动选择深耕/拓界领域，不依赖账号同步。

**Q：考古一直失败？**
A：看提示。`-412` 是 B 站风控，等 1 分钟或点“在 B 站搜索页打开”；网络问题检查是否能正常访问 B 站搜索。考古结果会缓存，重复查不会重复请求。

**Q：点击扩展图标没有数据？**
A：先刷新 B 站页面；如果当前标签不是 B 站，弹窗会显示“只在 bilibili.com 页面工作”。安装后必须刷新已打开的 B 站页面。

**Q：会不会影响 B 站正常功能？**
A：只添加本地 CSS 类和角标，不修改视频数据、不拦截网络请求（除了你主动触发的搜索）。关掉扩展或点“本页暂停”即可恢复。

**Q：能导出/同步到另一台电脑吗？**
A：设置页 → 导出配置，得到 JSON；另一台电脑导入即可。统计和缓存不导出。
